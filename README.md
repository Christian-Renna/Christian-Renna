🔬 Research

I work with Dr. Andreas Aristotelous (University of Akron) on mathematical biology. I implement a spatial model of bacterial infections treated with bacteriophages and antibiotics. The goal is to find effective combination-treatment strategies as antibiotic and phage resistance emerge.

The model simulates, on a 2D lattice:
Bacterial growth, replication, local competition, and inherited resistance
Individual phage particles moving via Brownian motion, adsorption, infection, latency, lysis, replication
Antibiotic diffusion and concentration across the spatial domain
Coupled PDE/ODE systems solved with finite difference methods (Euler, Crank–Nicolson, Theta method, Runge–Kutta, ADI, BDF)

It's built in Python with NumPy, SciPy, and Matplotlib. My role is on the computational side. I translate the algorithms into code, test the model, analyze the outputs, and profile the code to find bottlenecks and speed it up. This work sets up larger runs and, later on, optimization methods to search for good dosing and treatment strategies without having to test every combination in the lab.

I also just joined a combinatorial game theory team at Purdue under Dr. Mark Daniel Ward. We study the Sprague–Grundy values of subtraction games.

🎲 DC Deck-Building Engine

It also handles legal-action enumeration, privacy-safe observations, deterministic self-play, and a statistically grounded evaluation framework. Planned next:
